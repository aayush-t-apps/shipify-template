# Decisions (ADRs)

The current architecture, one decision at a time. Template: `guides/adr-template.md`. Write one
only for decisions that are hard to reverse or affect more than one project. An approved ADR keeps
its words; what changed after is in its "As built". Links to `docs/context.md` in older ADRs point
at a page ADR 0047 retired.

## ts-static 1.2.0: a `do` option (Durable Objects)

Nothing to change for an app that took no option: the upgrade only rewrites `cloudflare.mjs` (it
checks Durable Object classes, which such an app has none of) and one line of `AGENTS.md`. An app
that wants Durable Objects adds them as a change (big lane; `stacks/_cloudflare/storage.md`). Its
PRs then get no previews. The deploy token needs no new permission.

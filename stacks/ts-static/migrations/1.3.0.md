## ts-static 1.3.0: Node 26

Node 26, the LTS (supported to 2029-04-30), in place of Node 22. The upgrade rewrites `.nvmrc`, so
CI runs on Node 26. In `package.json`, set `engines.node` to `">=26"`, then `make verify`. Boxes
move to Node 26 by themselves (box setup 18). The app on Cloudflare doesn't change.
